## Scenario
A coffee shop receipt program that computes the subtotal, applies a member
discount, and displays the total, loyalty points, and order checks.

## How to Run
1. Go to https://dartpad.dev
2. Paste the code from `bin/dart_exercises.dart` into the editor.
3. Click **Run**.

## What It Demonstrates
- **Variables:** `int`, `double`, `String`, `bool` (explicit types)
- **Arithmetic operators:** `*`, `-`, `~/`
- **Comparison operator:** `>`
- **I/O:** `print()` with string interpolation
